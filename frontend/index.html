What this prototype can and can't do

Use these boundaries to avoid mistaking a demo for a clinical service.

It can now
Store a pet profile, check-ins and medication ticks in this browser; call the two image-analysis endpoints if the API is running; prepare a summary for you to share.
It cannot yet
Create a secure account, sync across devices, send medication reminders, message a veterinary team, persist records on a server, or notify a vet automatically.

PetTot is a prototype for recovery tracking and veterinary communication support. It is not an emergency service and does not provide a diagnosis.
